Šta je AgentMujoJob

Besplatan AI asistent za pronalazak posla: pretražuje oglase iz više izvora, razumije upite na prirodnom jeziku (npr. „Terenski komercijalist u Tešnju, plata najmanje 1.800 KM”), rangira rezultate po relevantnosti s obrazloženjem i vodi direktno na originalni oglas. Bez registracije, bez CV-jeva, bez historije pretrage — po dizajnu.

Geografski prioritet (promjenjiv): 1. BiH → 2. Balkan → 3. Evropa → 4. svijet + remote. Dostupno kao web aplikacija i Windows 11 desktop aplikacija na istom backendu.

Ključne karakteristike

🔍 Prirodni jezikZanimanje, vještine, grad, plata, remote/hibrid, ugovor — iz jedne rečenice.
🏆 Rangiranje 0–100Transparentna ocjena s razlozima za i protiv. Oglas bez plate se ne kažnjava.
🔌 Provjereni izvori10 izvora uživo testirano: Klix Posao i MojPosao.ba za BiH, plus Greenhouse, EURES, Remotive, RemoteOK i drugi.
🤖 AI jezgroOpenCode CLI s besplatnim modelom — radi bez prijave i bez ključeva.
🔒 PrivatnostNema naloga ni CV-jeva. Sirovi upiti se ne logiraju i ne pohranjuju.
🛡️ SigurnostSSRF zaštita, rate limiting, admin token, validacija ulaza — sve testirano.

Kako radi

Next.js web ──┐ ├──▶ FastAPI :8010 ──▶ Store: samo memorija (bez baze, bez diska) Tauri 2 .msi ──┘ konektori ▶ normalizacija ▶ dedup ▶ AI ▶ rangiranje

Brzi start

cd backend
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cp ../.env.example .env   # unesi jak ADMIN_TOKEN
venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8010

# probni sken (stvarni oglasi):
curl -X POST 127.0.0.1:8010/api/admin/scan -H "X-Admin-Token: TVOJ_TOKEN"

# frontend:
cd frontend && npm install && npm run dev   # http://localhost:3000
